# 🌙 Luna Emotion Companion

An AI-powered Emotion Intelligence Platform that analyzes emotions through speech and facial expressions, provides real-time emotional insights, wellness analytics, and personalized recommendations with the help of Luna, your emotional companion.

## Tech Stack

- Frontend: React + Next.js + TypeScript + Tailwind CSS
- Backend: FastAPI
- AI: PyTorch + Hugging Face + OpenCV + MediaPipe + DeepFace
- Database: PostgreSQL
- Real-Time: WebRTC + WebSockets + Redis
- Authentication: JWT
- Deployment: Docker
